# How to Read a Blood Report

## Reference ranges are population estimates, not individual targets
Every value on a blood report is printed next to a "normal" reference
range, but that range is typically defined as where about 95% of a
healthy reference population falls. This means roughly 1 in 20 healthy
people will have at least one value slightly outside the printed range
purely by statistical chance, with nothing wrong. A single mildly
out-of-range value is far less meaningful than a pattern across several
related values, or a value that is very far outside the range.

## Borderline vs. clearly abnormal
Values just outside the reference range ("borderline") often warrant a
repeat test or watchful monitoring rather than immediate treatment.
Values far outside the range, or values flagged as "panic" or "critical"
values by a lab, usually require prompt medical attention, since these
are thresholds at which labs specifically alert ordering physicians
because delay could be harmful.

## Context always matters
The same lab value can mean different things depending on age, sex,
pregnancy status, medications, recent illness, and even the time of day
or how recently someone ate. This is why an automated report reader
should be treated as a starting point for understanding a report, not a
replacement for a clinician who knows the fuller context of a person's
health.

## Reference ranges can differ between labs
Different laboratories sometimes use slightly different reference ranges
depending on their equipment, calibration, and reference population,
which is why the "normal range" printed on someone's report may differ
slightly from a range quoted elsewhere. When in doubt, the range printed
on the original report from the lab that ran the test should be treated
as authoritative for that specific report.
